### 🚀 About Me

I'm a software engineer who likes building things that actually run: web apps, mobile apps and backends. My electronics and automation background keeps me close to the real world, which is why I enjoy projects where software meets machines. I recently built a real-time digital twin of an industrial turbo-alternator at OCP's ManufacturiX Research Center (FastAPI, WebSocket, Redis, Dash/Plotly, AI modules), and I build full-stack apps with React, Django, React Native, Spring Boot and Flask.

Based in El Jadida / Casablanca, Morocco 🇲🇦.

🎓 &nbsp;**Master's in Intelligent Systems Engineering**, FSAC Casablanca (2026)  
🌍 &nbsp;Languages: **French (advanced) · English (intermediate)**

👯 &nbsp;I'm looking to collaborate on **Full-Stack, Industrial IoT &amp; Digital Twin projects**  
💬 &nbsp;Ask me about **Spring Boot, React / React Native, FastAPI, Digital Twins, Raspberry Pi**  
⚡ &nbsp;Fun fact: **I think in two worlds: "does the code compile?" and "does the machine stay safe?"**
